## 🚀 快速开始

```bash
# 1. 测试系统
python3 test_system.py

# 2. 运行系统（开发模式）
python3 supervisor.py

# 或使用快捷命令
./vigidoor.sh test    # 运行测试
./vigidoor.sh dev     # 开发模式启动
./vigidoor.sh logs    # 查看日志
```

# 🏗️ 智慧安防门 - 树莓派端完整软件架构

## 一、架构设计哲学

### 核心设计原则
```
1. 进程隔离：关键模块独立进程，故障不扩散
2. 自动恢复：任何组件崩溃都能自动重启
3. 降级运行：核心功能失败时切换到备用方案
4. 可观测性：实时监控所有组件健康状态
5. 防御编程：每个环节都有异常处理和超时保护
```

│  │  4. 进程间消息路由                                             │  │
│  │  5. 全局状态机管理（安全/警戒/报警）                           │  │
